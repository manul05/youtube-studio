# Music library

Put licensed music here and list every file in `index.json`:

```json
[
  { "file": "calm-investigation.mp3", "moods": ["documentary", "serious"], "bpm": 90,
    "licence": "YouTube Audio Library", "attributionRequired": false }
]
```

Use the YouTube Audio Library (YouTube Studio → Audio Library); it is free and safe for monetised videos. If a track says attribution is required, set `"attributionRequired": true` and copy its credit line into `"attributionText"`; the description will include it automatically.

Aim for 20–30 tracks across moods such as documentary, serious, tense, hopeful, mystery, energetic, upbeat, epic, calm.
